# Masidy AI - User Guide

Welcome to Masidy AI. This guide explains how to use Masidy and unlock its full potential.

## Getting Started

### Creating Your First Chat

1. Click **"New Chat"** in the sidebar
2. Select your preferred AI model from the dropdown
3. Type your message and click **Send**
4. Masidy responds instantly

That's it! Your conversation is saved automatically.

## Understanding AI Models

Masidy offers 5 specialized models optimized for different tasks:

### 🎯 Masidy Pro
**Best for**: General questions, creative writing, brainstorming
- Balanced performance and speed
- Great for most everyday tasks
- Default model for new users

### 🔬 Masidy Research
**Best for**: In-depth analysis, academic writing, research
- Provides detailed citations and sources
- Excellent for fact-checking
- Best for comprehensive information gathering

### 🎨 Masidy Creative
**Best for**: Writing stories, generating ideas, artistic direction
- Enhanced creativity and originality
- Great for marketing copy, poetry, fiction
- Best for unconventional thinking

### 💻 Masidy Code
**Best for**: Programming help, debugging, code reviews
- Understands all major programming languages
- Provides optimized code solutions
- Best for technical problem-solving

### 📚 Masidy Tutor
**Best for**: Learning new concepts, step-by-step explanations
- Patient and educational
- Breaks down complex topics
- Best for understanding fundamentals

## Tips & Tricks

### Getting Better Responses

1. **Be specific**: "Write a 500-word article about renewable energy" works better than "write about energy"
2. **Provide context**: Share relevant background information
3. **Use follow-ups**: Ask Masidy to elaborate, refine, or clarify
4. **Mention constraints**: "Under 200 words", "for beginners", "technical audience"

### Managing Conversations

- **Search**: Use sidebar to find past conversations
- **Delete**: Clear old chats from Thread Records
- **Share**: Export conversations as text
- **Resume**: Pick up where you left off anytime

### Switching Models Mid-Conversation

You can change models without losing context:
1. Select new model from dropdown
2. Continue chatting
3. Model switches immediately

### Clearing Your Workspace

Click **"Clear Chat"** in the header to start fresh while keeping your history saved.

## Troubleshooting

**"Message not sending?"**
- Check internet connection
- Try refreshing the page
- Switch to a different model

**"Getting slow responses?"**
- Try Masidy Pro (faster)
- Close unnecessary tabs
- Clear browser cache

**"Can't find old chat?"**
- Check sidebar Thread Records
- Use search feature
- Conversations saved for 30 days
