## Feature Highlights

### 📎 File Attachment

**What it does**: Add context by uploading files

**Supported formats**:
- Text: .txt, .md
- Code: .py, .js, .ts, .java, .cpp
- Documents: .pdf (Pro+)
- Data: .csv, .json

**How to use**:
1. Click attachment icon
2. Select file from computer
3. File context included in responses
4. Works mid-conversation

**Use cases**:
- Debug code by uploading files
- Analyze documents
- Process data files
- Research with sources

### 🔄 Model Switching

**What it does**: Change AI models without losing context

**How to use**:
1. Select new model from dropdown
2. Previous conversation stays intact
3. New model continues from where you left off
4. Switch anytime

**Why switch models**:
- Switch to Research for more detailed analysis
- Switch to Code for programming help
- Switch to Creative for ideation
- Compare responses across models

**Example workflow**:
```
1. Start with Masidy Pro: "Explain async programming"
2. Switch to Masidy Code: "Show me example async code"
3. Switch back to Pro: "When would I use this?"
```

## Limitations & Guidelines

### What Masidy Does Well

✅ Answer questions on vast topics  
✅ Provide code examples  
✅ Explain complex concepts  
✅ Generate creative content  
✅ Brainstorm ideas  
✅ Summarize information  
✅ Translate text  
✅ Debug code  

### What Masidy Can't Do

❌ Access the internet in real-time  
❌ Run code directly  
❌ Make function calls  
❌ Store files permanently  
❌ Process real-time data streams  
❌ Replace professional advice  
❌ Provide medical/legal guidance  

### Quality Tips

**For better results**:
- Be specific in your requests
- Provide context and background
- Ask follow-up questions
- Clarify if responses aren't right
- Correct misinformation
- Tell it your needs/constraints

## Tips for Best Results

### 1. Clear Communication

**Bad**: "Tell me about stuff"

**Good**: "Explain quantum computing basics for a beginner"

### 2. Provide Context

**Bad**: "Why is this not working?"

**Good**: "I'm getting an error 'undefined variable' in my Python script when I try to import pandas. Here's the code: [code]"

### 3. Follow-up Questions

**Chain requests**:
1. "What is machine learning?"
2. "Give me a real-world example"
3. "How would I start learning this?"

### 4. Use the Right Model

- Writing → Masidy Creative
- Coding → Masidy Code
- Learning → Masidy Tutor
- Research → Masidy Research
- General → Masidy Pro

### 5. Iterate

If response isn't perfect:
- Ask for clarification
- Request different format
- Ask for more/less detail
- Try different model

## Troubleshooting

### Getting Vague Responses

- Be more specific
- Provide more context
- Ask for examples
- Specify format/length

### Getting Wrong Information

- Verify with sources
- Ask for citations
- Request different approach
- Correct and resubmit

### Slow Responses

- Try faster model (Masidy Pro)
- Ask simpler question
- Check internet connection

### Can't Upload Files

- Check file format is supported
- File size under 10 MB
- Try different file type
