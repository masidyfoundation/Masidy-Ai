# Code of Conduct

## Our Commitment

We are committed to providing a welcoming and inspiring community for all. We expect everyone to follow this code of conduct.

## Expected Behavior

- Be respectful and inclusive
- Use welcoming and inclusive language
- Be patient and understanding
- Focus on constructive criticism
- Respect differing opinions and experiences

## Unacceptable Behavior

- Harassment, discrimination, or offensive language
- Personal attacks or trolling
- Publishing private information without consent
- Any form of abuse or bullying

## Reporting Issues

If you witness or experience unacceptable behavior, please report it to:
- Email: conduct@masidy.com
- GitHub: Report through GitHub's abuse tools

## Enforcement

Violations of this code of conduct may result in:
- Warning
- Temporary ban from community
- Permanent ban if severe

This Code of Conduct is adapted from the Contributor Covenant, version 2.0.
